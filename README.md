# Advanced Persistent Threat (APT) Detection with Graph Neural Networks

This repository contains a **Jupyter Notebook** that demonstrates **Advanced Persistent Threat (APT) detection** using **Graph Neural Networks (GNNs)**, specifically a lightweight **Graph Attention Network (GAT)**. The notebook covers the complete workflow: data preprocessing, graph construction, model training, evaluation, explainability, and visualization.

---

## Features

- **Graph Processing**
  - Preprocessing of PCA-transformed input data
  - Graph construction using K-Nearest Neighbors (KNN)
  - Graph structure visualization
  - Degree distribution plots

- **Model**
  - Lightweight Graph Attention Network (GAT)
  - Multi-head attention layers
  - Training, validation, and testing with stratified splits
  - Dropout and memory-efficient training

- **Evaluation**
  - Accuracy, confusion matrix (raw & normalized)
  - Classification report and per-class performance metrics

- **Explainability**
  - Subgraph visualization with edge importance
  - Feature importance heatmaps
  - Analysis of correct and incorrect predictions
  - Comparative attack pattern analysis

- **Persistence**
  - Versioned model checkpoints with timestamps
  - Model metadata including configuration, test accuracy, and class labels
